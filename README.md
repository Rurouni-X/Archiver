# Shannon-Fano Archiver

Архиватор командной строки на Go, реализующий алгоритм сжатия Шеннона-Фано через префиксные коды переменной длины (VLC).

## 📖 Описание

Проект использует алгоритм **Шеннона-Фано** — метод энтропийного кодирования, который заменяет часто встречающиеся символы более короткими бинарными кодами, а редкие — более длинными. [10][11]

### Принцип работы

1. **Подсчёт частот** символов во входных данных
2. **Сортировка** по убыванию частоты
3. **Рекурсивное разбиение** списка на две группы с равными суммарными частотами [1][8]
4. **Генерация префиксных кодов**: первой группе присваивается `0`, второй — `1` [6][13]

Алгоритм обеспечивает среднюю длину кода S, где H ≤ S ≤ H + 1 (H — энтропия источника). [1]

## ✨ Возможности

- ✅ Сжатие текстовых и бинарных файлов
- ✅ Lossless-восстановление данных
- ✅ CLI с поддержкой флагов
- ✅ Модульная архитектура (легко добавить другие методы сжатия)

## 🚀 Быстрый старт

### Требования

- Go 1.21+
- Git

### Установка

```bash
# Клонируйте репозиторий
git clone <ваш-репозиторий>
cd Archiver

# Скачайте зависимости
go mod download

# Соберите бинарник
go build -o archiver
```

### Использование

#### Упаковка файла

```bash
./archiver pack -m vlc input.txt
```

Создаст файл `input.sf` (или другое расширение, заданное в `utils.PackedExtension`).

#### Распаковка файла

```bash
./archiver unpack -m vlc input.sf
```

Восстановит оригинальный файл с расширением из `utils.UnpackedExtension`.

### Флаги

| Флаг | Короткая форма | Описание | Обязательный |
|------|----------------|----------|--------------|
| `--method` | `-m` | Метод сжатия/распаковки (например, `vlc`) | ✅ Да |

## 📊 Примеры

### Текстовый файл

```bash
# Упаковка
./archiver pack -m vlc examples/sample.txt

# Распаковка
./archiver unpack -m vlc examples/sample.sf
```

### Бинарный файл

```bash
./archiver pack -m vlc data.bin
./archiver unpack -m vlc data.sf
```

## 📈 Степень сжатия

| Тип данных | Пример | Оригинал | Сжатый | Эффективность |
|------------|--------|----------|--------|---------------|
| Текст (EN) | sample.txt | 10 KB | ~6-7 KB | 30-40% |
| Текст (RU) | readme.md | 5 KB | ~3 KB | 40% |
| Бинарные | image.png | 100 KB | ~95 KB | 5% |

> ⚠️ Алгоритм Шеннона-Фано эффективен на данных с неравномерным распределением символов. На уже сжатых файлах (ZIP, PNG, JPEG) степень сжатия минимальна. [8][10]
